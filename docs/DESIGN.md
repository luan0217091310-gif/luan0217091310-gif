# Midnight Lab

A personal workshop for Phùng Hữu Luân: a midnight desk, a friendly robot,
web experiments, and a little music. The illustration, project cards, activity
visualization, and footer are original SVG artwork generated by
`scripts/render_profile.py`. No external fonts, scripts, or image hosts are
needed to display the artwork.

## Design references

- [skulitom](https://github.com/skulitom): a consistent illustrated world across
  a profile, with subtle animation and mobile-specific artwork.
- [Platane](https://github.com/Platane): transforming contribution data into a
  playful visual that belongs to its owner.
- [DenverCoder1](https://github.com/DenverCoder1): readable navigation and clear
  links to the actual work behind a profile.

These are conceptual references. Their source code, artwork, and personal
biographies were not copied into this profile.

## Updating

Run from the repository root:

```sh
python scripts/render_profile.py
```

The script uses Python's standard library. The daily `Refresh Midnight Lab`
workflow also runs after generator changes, or manually from the Actions tab.
Its scheduled time is 01:23 UTC (08:23 in Vietnam); GitHub may delay scheduled
runs. GitHub can disable scheduled workflows after 60 days without repository
activity; if that happens, enable the workflow again from the Actions tab.

Change the palette, copy, scene, or cards in the generator, and edit the project
links and native text in `README.md`. Desktop and mobile layouts are generated
together. Animations honor the viewer's reduced-motion setting.

## Activity data

- Daily counts come from the same anonymous contribution-calendar page that
  GitHub displays publicly. Contributions include more than commits.
- The public-repository count comes from GitHub's REST API; private repositories
  are excluded. No private repository names or contents are read.
- Each bar represents one calendar week. Heights use the weekly count with a
  small constant baseline so that empty weeks remain visible. The moving
  playhead is decorative and does not change the values.
- The generator validates the parsed calendar against GitHub's displayed total
  before writing artwork. A failed fetch or changed calendar format leaves the
  existing SVGs in place.
- The cards display their refresh date. They remain available even if a later
  refresh fails; GitHub's image cache may delay showing a new image.

The Note App artwork is an illustration of the project, not a browser capture.
VocaPiano AI is presented as a research proposal, not a released application.
